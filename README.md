# Lududex

**Lududex** is a cross-platform game library manager written in Rust, designed
as a declarative alternative to Steam ROM Manager.

It discovers games and ROMs using configurable parsers and integrates them into
your Steam library as non-Steam shortcuts, complete with metadata and artwork.

Rather than relying on GUI-defined parsing rules, Lududex puts declarative
configuration first, making game discovery and library management reproducible,
portable, and easy to automate.

## Why the name?

**Lududex** combines *ludu*, derived from the Latin *ludus* (game or play), with
*dex*, short for *index*. The name reflects its purpose: discovering, indexing,
and organizing games.
